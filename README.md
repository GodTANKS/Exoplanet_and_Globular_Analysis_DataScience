# Exoplanet_and_Globular_Analysis_DataScience

## 외계행성계 탐사 · 구상성단 분포 데이터 사이언스 천문 교육 콘텐츠

실제 천문 데이터를 Google Colab에서 탐색·처리·분석·시각화하며  
**데이터 기반 천문학 탐구**를 경험하도록 개발한 교육 콘텐츠입니다.

이 저장소에는 두 가지 탐구활동이 포함되어 있습니다.

1. **외계행성계 탐사**
   - 외계행성계의 위치와 연도별 발견 특징 분석
   - 탐사 방법과 외계행성의 물리적 특징 간 관계 분석

2. **구상성단 분포를 이용한 우리은하 중심 찾기**
   - 구상성단의 2D·3D 공간 분포 시각화
   - 분포 자료를 이용한 우리은하 중심 위치 추론

## 관련 연구

**조훈 · 손정주, 「고등학교 천문학 수업에서 코딩을 활용한 데이터 기반 탐구활동의 활성화 방안 탐색」**  
현장과학교육, 16(5), 602–618, 2022.

본 연구에서는 고등학교 천문학 수업에서 실제 데이터를 활용해  
**데이터 수집 → 탐색 → 처리 → 분석 및 시각화**를 수행하는 코딩 기반 탐구활동을 개발하였습니다.

## 주요 파일

### 🪐 외계행성계 탐사

- `외계행성계 탐사_분석 코드.ipynb` — Google Colab용 분석 Notebook
- `exoplanet.eu_catalog_2022.csv` — 외계행성 분석 데이터

주요 분석 내용:
- 적경·적위 기반 외계행성계 공간 분포
- 발견 연도별 탐사 특징
- 외계행성 질량과 항성까지의 거리
- 탐사 방법과 질량·공전궤도 장축반경의 관계

### ✨ 구상성단으로 우리은하 중심 찾기

- `구상성단_분석 코드.ipynb` — Google Colab용 분석 Notebook
- `globular_clusters_list.csv` — 구상성단 공간 분포 데이터

주요 분석 내용:
- X·Y·Z 좌표 기반 2D/3D 분포 시각화
- 구상성단의 공간적 분포 탐색
- 분포 중심을 이용한 우리은하 중심 위치 추론
- 이상치 및 재처리 데이터 비교

## 실행 방법

이 콘텐츠는 **Google Colab** 사용을 권장합니다.  
별도의 Python 설치 없이 웹브라우저와 Google 계정만으로 실행할 수 있습니다.

### 외계행성계 탐사

1. `외계행성계 탐사_분석 코드.ipynb`를 내려받습니다.
2. Google Colab에서 Notebook을 엽니다.
3. `exoplanet.eu_catalog_2022.csv`를 Colab 세션에 업로드합니다.
4. Notebook의 셀을 순서대로 실행합니다.

### 구상성단 탐구

1. `구상성단_분석 코드.ipynb`를 내려받습니다.
2. Google Colab에서 Notebook을 엽니다.
3. `globular_clusters_list.csv`를 Colab 세션에 업로드합니다.
4. Notebook의 셀을 순서대로 실행합니다.

## 주요 Python 패키지

- pandas
- numpy
- matplotlib
- astropy *(외계행성계 탐사)*

Notebook 안에도 필요한 패키지 설치 코드가 포함되어 있습니다.
